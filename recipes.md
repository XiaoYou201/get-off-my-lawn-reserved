# Claim Cores

Each Claim Anchor is crafted around a matching **Claim Core** in the center slot.
Claim Cores are non-craftable, admin-only items handed out via `/give` (or the
creative tab). This means Claim Anchors can only be obtained with a core provided
by an admin — a plain vanilla Blaze Rod (which the core is displayed as) can *not*
be used in these recipes.

Each core carries the `毛世界` (Mao World) enchantment, from level I to VI:

| Core | Enchantment | Used by |
|---|---|---|
| Makeshift Core | 毛世界 I | Makeshift Claim Anchor |
| Reinforced Core | 毛世界 II | Reinforced Claim Anchor |
| Glistening Core | 毛世界 III | Glistening Claim Anchor |
| Crystal Core | 毛世界 IV | Crystal Claim Anchor |
| Emeradic Core | 毛世界 V | Emeradic Claim Anchor |
| Withered Core | 毛世界 VI | Withered Claim Anchor |
